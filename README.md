# Social Media Usage Survey — STA 281 Code

This repository contains the Python/Jupyter code for the university-student social-media survey project.

## Files
- `01_data_inspection_preprocessing.ipynb` — data loading, cleaning, descriptive statistics, five-number summary/IQR, z-scores, frequency tables, and plots.
- `02_hypothesis_testing_inference.ipynb` — correlation/covariance, probability, Bayes theorem, empirical PMF/CDF, CLT simulation, confidence interval, t-tests, ANOVA, regression, and behavioral analysis.
- `data/responses_survey_reconstructed.csv` — data reconstructed from the PDF export supplied for this project.
- `data/cleaned_social_media_survey.csv` — cleaned version generated by notebook 1.
- `requirements.txt` — Python packages needed.

## Important note about the supplied source
The uploaded source was a one-page PDF export rather than the original `.xlsx` file. The PDF contains 62 survey responses. Two source fields are visibly blank in the PDF: one respondent's age and one respondent's most-used social-media platform. Those values are preserved as missing (`NaN`) rather than guessed.

For the cleanest submission, keep the original Google Forms Excel export (`responses (survey).xlsx`) alongside the notebooks. Notebook 1 is written to use the original Excel file when it is present; otherwise it uses the reconstructed CSV.

## Run order
1. Put `responses (survey).xlsx` in the project root if you have it.
2. Open `01_data_inspection_preprocessing.ipynb` and run all cells.
3. Open `02_hypothesis_testing_inference.ipynb` and run all cells.
